# Discovery Workshop Agenda: Modern Data Platform

## Objective
Facilitate workshops and guide customers through solution options, risks and implications.

## Agenda (2 Hours)
1. **Current State Analysis (30 min):** Map existing pain points (e.g., slow reporting, siloed databases).
2. **Target State Vision (30 min):** Present high-level Medallion Architecture.
3. **Option Evaluation (45 min):** Compare Microsoft Fabric vs. Databricks for the specific workload.
4. **Next Steps (15 min):** Agree on Proof of Concept (PoC) scope.
