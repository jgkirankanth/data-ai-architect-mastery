# Welcome to the Data & AI Architect Mastery Repo! 🚀

If you found this via Twitter, this repository is designed to take you from intermediate data engineering to a confident **Data & AI Architect** or **Enterprise Data Architect**. 

## How to use this repository for maximum practical experience:

1. **Do not just read the code.** You must provision the free trials (Microsoft Fabric & Azure) and build this yourself.
2. **Follow the `WALKTHROUGH_*.md` files.** Inside the core folders (`01-microsoft-fabric-mastery`, `05-azure-ai-and-rag`, `13-enterprise-strategy`), you will find step-by-step practical guides. These tell you exactly what to click, deploy, and verify.
3. **Use the Architecture Templates.** When you build a solution, write a High-Level Design (HLD) using the `templates/` folder. This is the exact artifact hiring managers want to see in your portfolio.
4. **Practice the Interview Workbooks.** Head to `08-interview-and-job-prep` to practice defending your design choices.

**Prerequisites to start today:**
* An Azure Free Account
* A Microsoft 365 Developer Tenant (for Entra ID access)
* Microsoft Fabric 60-Day Trial activated on that tenant
* VS Code & Git installed locally
